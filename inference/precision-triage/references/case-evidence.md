# 历史案例：用于选择假设，不能代替当前证据

这些案例来自用户的历史记录与 2026-11-16 对话整理。运行结果是特定版本和样本的历史证据；私有提交没有在本 skill 创建过程中独立获取或验证。

| 案例 | 可复用定位动作 | 结论边界 |
|---|---|---|
| FlashAttention d128 反向间歇跳变 | 固定输入/上游梯度、逐个梯度比较、shape/heads/batch 扫描、同物理卡新旧回切 | 指定新版 1000 次无异常、旧版同卡复现支持版本相关异常；没有证明具体 ISA 根因。1000 次不是通用必测数。 |
| DSPARK verify 宽度 6 的 compress ring 少写 | 追到 HCU 实际 `_out` 入口，核对 GPU pad 与 CPU 写入边界，并查 JIT 加载哈希 | 补丁生效与具体 planner 缺陷修复已有记录；空回答未明显减少，不能把二者合并为已解决。 |
| DSV4 提前 EOS / 空回答 | 检查停止字段，保存完整前缀；比较 EOS 和正常续写候选；对照 prefill/decode | 长度上限已排除、EOS 异常分布可复现；共用路径范围包括 MoE 等，最终根因需受控修复重放。 |
| MoE 路由切换漏 SwiGLU clamp | 比较两次 GEMM 之间模型要求的激活/clamp/量化；核对实际 runner | 用户报告私有提交引入/修复路径切换，提供了 legacy 与新 runner 的不同调用链。未独立核验 diff，尚不能把历史 EOS 现象归因到它。 |
| reasoning_effort 映射 | 核对实际注入模板和 token IDs，再看同题多轮质量/长度 | 相同 effort 名称曾映射不同输入语义；配置问题应在入口分流。输出长度差异本身不证明数值异常。 |
| FP32 与 TF32 权衡 | 明确计算模式许可、参考和误差阈值，再讨论性能 | 历史误差记法含糊，不能补成确定阈值；不能用精度模式变化造成的加速宣称同精度优化。 |

案例材料无法访问时照常应用通用流程，不要求用户提供内部主机、账号或完整历史数据库。复用材料时只记录当前任务必要的证据定位。
