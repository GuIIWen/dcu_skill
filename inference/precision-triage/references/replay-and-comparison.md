# 固定输入与比较方法

按症状选择生成、训练或量化段落；不要求全部执行。

## 生成输出分叉 / 提前 EOS

1. 保存服务端原始响应、finish_reason、stop 配置、输出上限、输出 token IDs 与 reasoning/content。区分长度上限、显式 stop、实际 EOS、解析空正文、请求/传输失败。
2. 冻结异常 token 之前的**完整 token prefix**，包括模板、系统提示、工具历史、effort 注入和位置/mask。token 数相同不足以证明输入相同；字符串重编码可能改变 token 边界。
3. 同一 prefix 上比较下一 token 的候选 logits/概率、正确续写候选与 EOS 排名、候选间距。尽量保存采样过滤前的 logits；只有 top-k logprobs 时标明截断和不可观测部分。EOS 是否合理要结合任务与参考，不能因其概率高就宣布计算错误。
4. 依次按需要对照 teacher-forced 前向、增量 decode、服务端生成。前向对齐而增量不同，检查 KV/位置/状态；增量对齐而服务不同，检查模板、请求转换、采样和解析。只有观测匹配足以支持时才缩小范围。
5. prefill 与 decode 均异常时检查共用部分：MoE、权重/scale、归一化、attention/indexer、量化与缓存语义；仅一侧异常也先核对输入、状态和实际 dispatch。

文本不同、temperature=0、固定 seed 均不单独构成数值异常或跨后端确定性保证。自由生成一旦分叉，后续 token 不能继续当作相同输入直接比较。

## 训练 / 算子重复性

固定输入、权重、上游梯度及支持的 mask/layout，分别比较输出和每个相关输入梯度。记录正常波动、异常 m/n 与误差坐标；扫描 shape、head_dim、batch、heads、尾部或 stride 时保持其他条件。

误差集中在某个 dim/tile，只能引导检查索引、布局、写回或同步，不能单独证明 scale 索引错误。deterministic 标志没有消除异常，也不等于已证明硬件故障。异步报错的落点可能不是最早出错的 kernel。

## 量化 / MoE 语义

分段比较输入 → GEMM-1 → 激活/clamp → 量化数据与 scale → GEMM-2。必要时用相同 GEMM-1 输出离线验证激活、clamp 和量化步骤，区分前级输入变化与后级实现差异。

先写清模型要求的计算：clamp 对象与位置、scale 的方向与粒度、布局、舍入/饱和规则、累加 dtype、epilogue 顺序。config 中有参数，仍需证明运行时读取并实际使用。

FP8、INT8 和低比特整数各自建参考。`0.5 × scale` 仅能在相应均匀整数最近舍入、无饱和等前提下讨论单次量化误差；不能作为 FP8、GEMM 输出或模型任务的通用阈值。不要为了适配检查器把 FP8 路径换成 INT8。

可以分别比较：已量化权重/激活的算术实现误差，以及量化相对原始模型引入的误差。报告两者的参考与范围，不混成一个“精度差”。

## 采集器与参考的自检

- 检查抓取的层、token、rank、有效长度、mask 和张量布局是否相同；采集是否拿到后续被修改的 alias。
- 用已知相等的离线输入检查对齐；用可控局部差异检查检测能力。差异注入只用于隔离样本/checker 验证，不改生产请求或 evaluator 的原始参考。
- dump 保留原 dtype 元数据和必要值；转 FP32 方便分析不能恢复之前丢失的精度。采集同步与 profiler 会改变执行时序，必要时无插桩复验原始故障。
- 先选阶段/层段，避免默认保存所有层、所有 token 的完整张量；记录磁盘和请求预算。

## 比较与结论

按任务选择 max/P99 绝对误差、相对误差及分母定义、超阈值个数与非有限值位置。近零参考同时看绝对误差。保留 checker 的有效区域、比较方向和 NaN 策略；不把余弦相似度作为唯一门槛。

版本二分需要稳定、成本可控的 good/bad 判据。构建失败、OOM、服务不可达或目标路径未触发标为跳过/不可判定，不当成 accuracy bad；间歇故障按同端发生率设计重复与停止条件。

结论按证据逐级表述：现象可复现 → 与某配置/版本相关 → 定位到算子/语义 → 受控修复消除目标缺陷 → 原始任务改善。允许停在已证实层级，明确下一项缺失证据。
